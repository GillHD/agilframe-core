# Быстрый старт

Запустите Core из корня проекта по командам из [README](../../README.md#быстрый-старт). Core слушает порт 8787 по умолчанию. Проверьте доступность с `curl http://localhost:8787/v1/health`.

1. Откройте `http://localhost:8787/dashboard/` и войдите с ключом локальной разработки `dev-key`.
2. Создайте комнату в разделе «Комнаты». Для автоматизации воспользуйтесь [пошаговым примером REST](../../agil/core/docs/api-guide.md).
3. Откройте ссылку участника в браузере. Для второго участника выпустите отдельный join-токен. Разрешите доступ к камере и микрофону.
4. Откройте `/wiki/` для настройки функций, `/editor/` для оформления и `/custom-ui.html` для примера своего интерфейса.

Для устройств в разных сетях понадобится доступный медиамаршрут. О настройке TLS, TURN и SFU см. [эксплуатацию](../operations/README.md).
