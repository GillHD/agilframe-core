# AgilFrame security

[Русский](SECURITY.md) · **English**

Report suspected vulnerabilities through GitHub private vulnerability reporting. Use public issues for bugs and feature requests. [Submit a private report](https://github.com/GillHD/agilframe-core/security/advisories/new)

Include the version or commit SHA, relevant configuration, affected scope, and enough detail for a maintainer to check the issue. Remove keys, tokens, participant data, and production environment addresses. Run checks only against systems you are authorized to test.

The maintainer uses the private report to ask questions, coordinate a fix, and prepare a security advisory. Follow published advisories and upgrade to releases containing fixes. [Security advisories](https://github.com/GillHD/agilframe-core/security/advisories)

Dependabot monitors dependencies for known vulnerabilities. CodeQL analyzes the source code. A scheduled npm check maintains one public issue summarizing npm advisories that are already public. Use the private reporting channel for vulnerabilities in AgilFrame itself.
