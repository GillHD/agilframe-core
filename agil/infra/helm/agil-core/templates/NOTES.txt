{{- if not .Values.secrets.existingSecret }}

GitOps warning: generated secrets use randAlphaNum and are preserved only by a
live `helm upgrade` lookup. `helm template`, ArgoCD, Flux and other renderers
cannot query the cluster and will rotate AGIL_TOKEN_SECRET/AGIL_IP_SALT/API key
on every sync (invalidating join links and sessions). For GitOps set
`secrets.existingSecret` to a pre-created Secret instead of generating values.
{{- end }}

{{- if and .Values.podDisruptionBudget.enabled (le (int .Values.replicaCount) (int .Values.podDisruptionBudget.minAvailable)) }}

NOTE: podDisruptionBudget.enabled with replicaCount={{ .Values.replicaCount }} and
minAvailable={{ .Values.podDisruptionBudget.minAvailable }} would block every
node drain. The chart renders maxUnavailable: 1 instead (a no-op at one replica).
Real disruption protection needs replicaCount > minAvailable, which core 0.1.0
does not support.
{{- end }}

Node enrollment (optional):
  1. Create a one-time node token (dashboard → Cluster/Nodes or
     POST /v1/admin/cluster/tokens with kind=node).
  2. Install the node chart:
       helm install agil-node infra/helm/agil-node \
         --set core.url=http://{{ include "agil-core.fullname" . }}:{{ .Values.service.port }} \
         --set enrollment.existingSecret=<secret-with-token>

Upgrade:  helm upgrade --install {{ .Release.Name }} agil/infra/helm/agil-core -f my-values.yaml
Rollback: helm rollback {{ .Release.Name }} <revision>
