# Адаптивный интерфейс звонка

AgilFrame использует один виджет для полноэкранного звонка, iframe и компактного встраивания. Внешний контейнер задаёт размеры, а виджет раскладывает видео, панель управления и боковые области по доступному пространству.

- Видеоплитки сохраняют полный кадр. В компактном окне интерфейс освобождает место под видео и основные кнопки.
- Панель управления переносит дополнительные действия в меню, когда кнопки перестают помещаться.
- Настройки микрофона, камеры и фона используют тему звонка и учитывают границы контейнера.
- Внешние приложения могут передать тему, настроить компоновку или собрать собственный интерфейс на Web SDK.
