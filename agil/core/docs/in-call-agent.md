# In-call AI-агент, права пользователя и spotlight-подсказки

В звонке у пользователя есть ассистент: можно попросить «включи запись», «открой
чат», «как поменять камеру?» — и агент либо **выполняет действие**, либо
**подсвечивает нужную кнопку** (затемняет интерфейс и показывает, куда нажать).
Агент действует **строго с правами пользователя**: он физически не может
сделать больше, чем разрешено ролью/политикой тенанта.

## 1. Что умеет

| Действие | Tool | Требует |
|---|---|---|
| Начать/остановить запись | `start_recording`, `stop_recording` | фича `recording` + роль host/moderator |
| Микрофон/камера | `toggle_mic`, `toggle_camera` | доступ к устройствам на клиенте |
| Поднять руку | `raise_hand` | `handRaise` |
| Демонстрация экрана | `toggle_screen_share` | `screenShare` |
| Открыть чат/файлы/участников/заметки/настройки | `open_chat`, `open_files`, `open_participants`, `open_notes`, `open_settings` | соответствующая фича (`chat`, `fileShare`, `participantList`, `meetingNotes`, `deviceSettings`) |
| Блюр фона | `set_blur` | `backgroundBlur` |
| Свернуть/развернуть/фуллскрин/новая вкладка | `minimize`, `restore`, `request_fullscreen`, `open_new_tab` | `fullscreen` (для фуллскрина) |
| Скопировать приглашение | `copy_invite_link` | `inviteLink` |
| Подсказка «куда нажать» | spotlight (не действие) | `session.inCallAgent.spotlight` |

Полный список — `agil/core/packages/protocol/src/assistant.ts` (`assistantTools`,
`assistantToolRequirements`). Клиент и сервер используют **одну и ту же**
функцию прав `isAssistantToolAllowed`/`filterAssistantActions`: LLM не может
предложить действие, которое пользователю недоступно (отфильтровывается), а
сервер повторно проверяет права и аудирует.

## 2. Режимы

`TenantConfig.session.inCallAgent`:

| Поле | Смысл |
|---|---|
| `enabled` | включён ли ассистент (по умолчанию да) |
| `mode` | `local` (офлайн-правила, без LLM), `external`, `hybrid` (LLM + локальный fallback) |
| `endpoint`, `apiKeyEnv`, `timeoutMs` | внешний LLM-агент (HTTPS + HMAC; ключ только в env) |
| `systemPrompt`, `model` | дополнительная инструкция организации и имя внешней модели |
| `compressContext` | попросить внешний агент сжимать историю сообщений. По умолчанию выключено |
| `spotlight` | разрешить подсветку элементов UI |
| `allowedTools` | какие инструменты вообще доступны в тенанте |
| `maxActionsPerReply` | лимит действий на один ответ (1..10) |
| `audit` | писать `assistant.usage` в аудит |
| `denyMessage` | текст при отказе по правам |

**local (по умолчанию)** — детерминированный разбор фраз (ru/en), без сети:
понимает «включи запись», «открой чат», «где микрофон», «как включить фон» и
строит spotlight-tour. Работает автономно, нулевая стоимость, ноль утечек.

**external** — запрос уходит в корпоративный LLM-агент (любая нейросеть за
прокси, см. `agil/core/docs/llm-integrations.md`), который возвращает текст, действия и
подсказки. Ответ валидируется zod, действия фильтруются правами.

### Сжатие истории

В редакторе откройте **Ассистент звонка**, выберите режим **Внешний** или
**Гибридный** и включите **Сжимать историю разговора** рядом с полем модели.
Сохраните конфигурацию организации. Core передаёт адаптеру
`contextCompression: { enabled: true, preserveSystemPrompt: true }`.
Core отправляет текущий вопрос. Если адаптер ведёт историю, он сжимает только
сообщения предыдущих ходов и хранит их в рамках той же организации, комнаты и
участника. Эта настройка требует поддержки со стороны адаптера.

Core добавляет полный базовый набор правил из
`apps/server/src/in-call-security-rules.ts` в каждый запрос к внешней модели.
Полный подписанный текст политики и дополнительная инструкция организации
входят в тот же `systemPrompt`. Адаптер передаёт полученный `systemPrompt`
целиком в системной роли при каждом обращении к модели, в том числе после
сокращения или восстановления истории. Если запрос превышает контекстное
окно, адаптер сокращает историю или возвращает ошибку.

## 3. Spotlight (подсветка «куда нажать»)

Ассистент возвращает `spotlight: [{target, text, step?}]`. Виджет:

1. затемняет весь интерфейс (overlay, `backdrop` + dim);
2. находит элемент по логическому имени (`mic`, `camera`, `screen`, `chat`,
   `files`, `participants`, `notes`, `settings`, `blur`, `recording`,
   `minimize`, `fullscreen`, `newtab`, `invite`). Для внешнего агента
   применяются только доступные участнику цели из этого списка;
3. рисует подсветку (кольцо/пульс) и подсказку-стрелку с текстом;
4. для многошаговых туров — кнопки «Далее/Назад/Понятно», шаги `step`.

Работает и как тур по функциям («покажи, как включить запись»). A11y: overlay
закрывается Esc, фокус на подсказке, `aria-live` для текста, не блокирует звонок.

## 4. Wire-протокол

Ассистент вызывается из виджета:
`POST /v1/rooms/:roomId/assistant` (`authorization: Bearer <join token>`,
тело `{text, locale?, state?}`) → `AssistantReply {text, actions, spotlight, source, securityPolicy?}`.
Сервер:

1. проверяет токен, доступ участника к комнате, `session.inCallAgent.enabled` и rate-limit
   (10/мин на участника);
2. `mode=local` → `501 assistant_local_only` с подсказкой (виджет исполняет
   локальный движок сам, без сети);
3. `external/hybrid` → `POST endpoint` с `InCallAssistantRequest`
   (`participant.permissions`, `tools`, `state`, `systemPrompt`, `model` при
   настройке, `contextCompression`, HMAC-подпись при настроенном ключе),
   ответ `InCallAssistantResponse` валидируется `parseInCallAssistantResponse`;
4. отбрасывает действия, не проходящие `filterAssistantActions`, обрезает до
   `maxActionsPerReply`, пишет аудит `assistant.usage`, возвращает reply.

Виджет исполняет действия только после проверки `isAssistantToolAllowed` (UX),
сервер — источник истины (enforcement).

## 5. Безопасность

- **Нет эскалации прав:** LLM не может записать/поделиться экраном/открыть
  данные, если у пользователя нет фичи; инъекция в промпт («игнорируй права»)
  не проходит серверный фильтр.
- Действия внешнего агента, меняющие состояние или отправляющие данные,
  требуют подтверждения участника. Это включает микрофон, камеру, экран,
  запись, чат, поднятие руки, фон, копирование ссылки и открытие новой вкладки.
  При подтверждении виджет повторно проверяет текущие права. Для записи
  также действует штатный запрос согласия.
- **Prompt injection:** пользовательский текст и транскрипт — данные, не
  инструкции; ответы только по схеме, без цепочек tool-calling с произвольными
  параметрами (args ограничены и не исполняются сервером).
- Адаптер получает текущий вопрос, контекст участника, компактное состояние
  и список доступных инструментов. Потоки аудио и видео и история чата
  комнаты в запрос не входят. Ключ считывается из окружения сервера.
- `enabled:false` отключает ассистента. Пустой `allowedTools` отключает
  выполнение действий. `spotlight:false` отключает подсветку.

### Подписанная политика организации

1. Подготовьте JSON с полями `tenantId`, `endpoint`, `version`,
   `environment` (`production` или `test`), `expiresAt` (ISO 8601 в UTC),
   `allowedTools` и `instructions`. Для рабочего агента используйте HTTPS.
2. Подпишите точные UTF-8 байты JSON ключом Ed25519. Сохраните файл в формате
   `{ "payload": "<исходный JSON как строка>", "signature": "<подпись base64>" }`.
   Ограничение файла составляет 16 КиБ. Поле `instructions` принимает до
   8 000 символов.
3. Задайте `AGIL_INCALL_POLICY_PATH` с путём к файлу и
   `AGIL_INCALL_POLICY_PUBLIC_KEY` с открытым ключом PEM. Текущая конфигурация
   Core принимает один подписанный файл для указанной организации и её
   внешнего адреса. Закрытый ключ остаётся у подписывающей стороны.
4. Откройте звонок под ролью участника и отправьте запрос. После проверки
   версии, подписи, срока, привязки и ответа по тому же ID Core возвращает
   `securityPolicy` с окружением и версией. Виджет показывает рабочую или
   тестовую отметку, а аудит при включённой настройке записывает версию и
   окружение. Отметка удостоверяет подписанную конфигурацию и факт ответа
   связанного сервиса.

При недействительном файле Core возвращает `assistant_policy_unverified`.
В гибридном режиме с подписанной политикой сбой внешнего сервиса завершает
запрос ошибкой. И подписанный список инструментов, и список организации,
и права участника применяются одновременно.

## 6. Примеры

- «Включи запись» → `start_recording` + подсветка кнопки записи (если роль host).
- «Где чат?» → текст + spotlight на кнопку чата.
- «Покажи, как включить размытие фона» → тур: шаг 1 — кнопка фона, шаг 2 —
  настройки фона.
- «Открой заметки и найди, что решили по бюджету» → `open_notes` (затем
  knowledge-ассистент отвечает по транскрипту).
- «Начни запись и пригласи Аню» → `start_recording` + `copy_invite_link`.
