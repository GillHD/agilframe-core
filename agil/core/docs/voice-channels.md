# Постоянные голосовые каналы

Голосовой канал хранит стабильный идентификатор, название и список участников организации. При выдаче доступа Core создаёт закрытую групповую комнату или переиспользует уже активную. В комнате работают обычные возможности звонка, включая звук, камеру, демонстрацию экрана и события участников. Права на эти действия определяют назначенная роль и политика организации.

## Создать канал

Сервер вашей компании вызывает административный API с ключом организации. В примере идентификаторы участников совпадают с идентификаторами учётных записей в корпоративном сервисе.

```http
POST /v1/admin/voice-channels
Content-Type: application/json
x-api-key: <tenant-api-key>
```

```json
{
  "id": "engineering",
  "name": "Инженерная команда",
  "members": [
    { "participantId": "staff-alice", "name": "Алиса", "role": "moderator" },
    { "participantId": "staff-bob", "name": "Борис", "role": "guest" }
  ]
}
```

Ответ `201` содержит `channel`. В пределах одной организации идентификатор канала уникален. Каждая запись участника содержит корпоративный `participantId` и одну из ролей `host`, `moderator` или `guest`. Пустой список оставляет канал без участников.

## Подключить участника

1. Ваш сервер проверяет сессию пользователя и получает его стабильный корпоративный идентификатор.
2. Ваш сервер отправляет `POST /v1/admin/voice-channels/engineering/join` с телом `{"participantId":"staff-bob"}` и ключом организации.
3. Ответ содержит `channelId`, `roomId`, `token`, `expiresAt` в миллисекундах Unix и `joinUrl`. Клиенту передаются `roomId` и `token` для обычного подключения через Web SDK. Ключ организации остаётся на вашем сервере.

Core выдаёт краткоживущий допуск до пяти минут с ролью из списка канала. URL подключения также содержит этот допуск. Участник с другим `participantId` получает `403`, а запрос канала другой организации получает `404`. При обязательном корпоративном OIDC передайте в стандартное подключение также `identityToken` с тем же идентификатором.

## Править состав и восстанавливать доступ

| Запрос | Результат |
| --- | --- |
| `GET /v1/admin/voice-channels` | Список каналов и составов организации |
| `GET /v1/admin/voice-channels/{channelId}` | Один канал и назначенные роли |
| `PATCH /v1/admin/voice-channels/{channelId}` | Переименовать канал или заменить список `members` целиком |
| `DELETE /v1/admin/voice-channels/{channelId}` | Удалить канал и закрыть текущую комнату |

Смена состава, ролей или назначенного имени участника закрывает текущий звонок. В следующий раз Core выдаёт допуск для новой комнаты. При простом переименовании канала или перестановке строк состава текущая комната сохраняется.

Реестр хранится в каталоге данных Core. При настроенном Redis реестр записывает лидер, а новые лидеры читают ту же версию канала. После перезапуска Core клиент повторяет получение допуска через сервер компании. Канал и назначенные роли сохраняются, имя комнаты и идентификатор участника восстанавливаются, а для новой медиасессии создаётся новый `roomId`. Неиспользуемая комната освобождается по сроку простоя.

## Переключить канал в интерфейсе

Создайте один `createVoiceChannelSwitcher` на область звонка. `getGrant` обращается к маршруту вашего приложения, который проверяет сессию пользователя и запрашивает допуск у Core. SDK получает допуск, завершает прежнюю сессию и подключает выбранную комнату. Если сервер отклоняет запрос нового допуска, текущий звонок продолжается.

```js
import { createVoiceChannelSwitcher } from '@agil/calls-sdk';

const channels = createVoiceChannelSwitcher('#voice', {
  call: { ui: 'headless' },
  async getGrant(channelId, signal) {
    const response = await fetch('/api/voice-channels/' + encodeURIComponent(channelId) + '/join', {
      method: 'POST',
      signal,
    });
    if (!response.ok) throw new Error('Не удалось открыть голосовой канал');
    return response.json();
  },
});

const session = await channels.switchTo('engineering');
const call = session?.call;
// Получайте состояния камеры, микрофона, экрана и говорящих через методы звонка.
await channels.leave();
```
