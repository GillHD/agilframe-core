# Кастомизация лейаута: стили контролов, «плавающий остров», скрытие кнопок

Помимо темы (цвета/типографика/радиусы) компания настраивает **расположение и
состав элементов управления** — от классической нижней панели до популярного
«плавающего острова» с кнопками. Всё задаётся в `TenantConfig.layout`, работает
через API, редактор, MCP и дашборд, применяется в рантайме (`updateConfig`).

## 1. Поля конфига

```jsonc
{
  "layout": {
    "mode": "grid",                 // grid | spotlight | sidebar
    "selfView": "corner",           // corner | pip | hidden
    "controlsStyle": "island",      // bar | island | minimal
    "controlsAnchor": "bottom-center", // bottom-center | bottom-left | bottom-right | top-center | top-right
    "hiddenControls": ["blur", "recording", "transcript"],
    "controlOrder": ["mic", "camera", "screen", "chat", "leave"],
    "autoHideControls": true,
    "autoHideDelaySec": 5,
    "chatPosition": "right",
    "chatDefaultOpen": false,
    "chrome": "none",               // full | compact | none
    "minimized": { "enabled": true, "mode": "bubble", "position": "bottom-right" },
    "showRoomName": true,
    "showParticipantCount": true,
    "showQualityIndicator": true,
    "showTimer": true,
    "tileAspectRatio": "16:9",
    "gridMaxTiles": 9,
    "spotlightFollowSpeaker": true,
    "persistAcrossPages": false,
    "inheritHostStyles": false
  }
}
```

### Идентификаторы контролов (`controlIds`)

`mic`, `camera`, `screen`, `blur`, `chat`, `hand`, `reactions`, `participants`,
`notes`, `transcript`, `assistant`, `recording`, `fullscreen`, `newtab`,
`minimize`, `settings`, `leave`.

`hiddenControls` — полностью скрыть у тенанта (API-методы и горячие клавиши
остаются, если фича разрешена правами). `controlOrder` — явный порядок; элементы
вне списка идут после в дефолтном порядке.

## 2. Стили контролов

| `controlsStyle` | Вид |
|---|---|
| `bar` | классическая нижняя панель (по умолчанию), все кнопки в ряд |
| `island` | **плавающий остров**: компактная пилюля с ключевыми кнопками (mic, camera, screen, chat, leave) + меню «⋯» для остальных; полупрозрачный фон, blur, тень, скругление; позиция из `controlsAnchor` |
| `minimal` | только mic/camera/leave + «⋯» (для встраивания в чужой UI и мобильных) |

- `controlsAnchor` задаёт позицию острова/панели внутри виджета.
- `autoHideControls` — плавное скрытие по простою (`autoHideDelaySec`), появление
  на движение мыши/тап/фокус; не влияет на доступность (Tab/скринридер).
- На мобильных `island` автоматически сжимается; меню «⋯» — popover.
- В режиме `chrome:'none'` контролы остаются, но без фона и «полной» шапки
  виджета. Исключение — **embedded desktop** (см. §4): там включается
  компактная шапка звонка с переключателем вида, потому что хост-страница не
  может управлять видом виджета; фон всё равно прозрачный.

## 3. API и инструменты

- REST: `PATCH /v1/tenants/:id/config` `{layout:{...}}`; виджет подхватывает при
  следующем `welcome`/`config` broadcast (или `instance.updateConfig({layout})`).
- Widget API: `updateConfig({layout})`, `getState().config.layout`;
  data-атрибуты для e2e: `data-agil-controls-style`, `data-agil-controls-anchor`,
  `data-agil-control="mic|camera|..."`, `[data-agil-more]`.
- MCP: `agil_update_config`/`agil_apply_theme_to_config` (layout — часть конфига),
  `agil_explain_feature` по layout; в редакторе — секция «Лейаут».
- Дашборд: настройки лейаута в «Настройках/Встраивании»; превью через редактор.

## 4. Демо-страницы (сравнение)

| Страница | Что показывает |
|---|---|
| `/` (default) | «из коробки»: фирменный стиль AgilFrame, светлая/тёмная тема, классический bar/остров по переключателю |
| `/index.html` | **пример интеграции в стиле example.com**: тёмный фон, Inter, фиолетовый акцент `#8576ff`, поверхности `#0e1522/#121b2c`, моно-логотип `embedded call`, встроенный звонок без собственной шапки (`chrome:'none'`), внутренний чат скрыт (чат остаётся в мессенджере компании), мини-окно/bubble. На десктопе с тонким указателем виджет сам включает компактную шапку звонка и горизонтальный прямоугольный док (см. ниже), а страница прячет дублирующую шапку карточки. |

Обе страницы используют один и тот же SDK/виджет и различаются только
конфигом тенанта/`options`: тема, `layout`, скрытые контролы, брендинг. Это
демонстрирует «тот же продукт — другой дизайн» без форка кода.

### embedded call: встроенный десктопный звонок

`controlsStyle:'island'` остаётся конфигом для тач-устройств. Если виджет
встроен (`embedded:true`), `chrome:'none'`, указатель тонкий (`pointer:fine`) и
карточка/вьюпорт достаточно широкие (≥600 px карточка или ≥760 px вьюпорт),
виджет включает **embedded desktop**:

- компактная шапка 44 px: комната/таймер, статус, число участников и
  единственный переключатель «Сетка/Спикер» (плюс навигация по страницам)
  справа; отдельная полоса пейджера 52 px удаляется;
- нижний **плавающий** док-остров поверх видео (`width: fit-content`, 295–391 px,
  по центру): отступ 12 px снизу и не меньше 12 px по бокам, радиус 16 px,
  рамка/тень/blur; **без зарезервированной полосы** — сетка/видео доходит до
  низа карточки и остров перекрывает его на 60 px. Кнопки 38 px (радиус 9 px)
  в одной плотной строке: микрофон + разделённая камера (4 px) │
  экран/чат/«⋯» (4 px) │ красная «Выйти»; между группами 8 px + разделитель
  1 px, без `space-between` и пустых ячеек. Подписи нижнего ряда плиток
  поднимаются на 64 px внутри overlay плитки, поэтому видео остаётся за
  островом, а имя/статус не перекрываются;
- поверхность звонка — настоящие 16:9: карточка embedded call задаёт
  `height: calc(56.25cqw + 44px)`, а на других пропорциях (680×760, 1440×900)
  плитки заполняют кадр через `object-fit: cover` без letterbox-полосы;
- prejoin-лобби компактное: две колонки на десктопе (превью ≈55 % / форма
  ≈45 %), «Подключение», имя, «Войти», «Только слушать» и маленький «?» с
  горячими клавишами; длинный URL и абзац подсказок убраны, скролла нет;
- меню «⋯» — **горизонтальный плавающий островок**: один ряд компактных
  чипов 50 × 54 px (иконка 18 px над короткой подписью 9.5 px), ширина
  `fit-content` не более 460 px, отступ 12 px от дока, края 16 px,
  рамка/тень/blur. Действия сгруппированы по «Медиа / Встреча / Настройки»
  тонкими разделителями 1 px и разнесены на 4 px; короткие подписи
  (`PiP / Экран / Вкладка / Свернуть / Рука / Реакции / Опросы / Настройки`)
  всегда сопровождаются полным `title`/`aria-label`. Восемь действий
  помещаются целиком на 680/1024/1440; если хост уже не вмещает ряд, панель
  прокручивается по горизонтали, а не переносится в колонки. Панель
  центрирована над доком и не касается краёв карточки;
- шапка карточки embedded call скрывается, пока активна шапка виджета; футер
  «АУДИТ ВКЛЮЧЁН / Свернуть окно» остаётся одной компактной строкой (32 px
  кнопка на десктопе, 44 px на тач).

На тач-устройствах и в обычном full-chrome виджете поведение не меняется:
остров 44 px, пейджер 52 px. Политика и пороги:
`agil/websdk/widget/src/ui/call-chrome.ts`; доказательства:
`agil/core/qa/call-ui-v3/embedded call-capture.mjs`.

### Зал ожидания в embedded call

Когда в настройках комнаты включён `security.waitingRoom`, ссылка гостя открывает экран ожидания. Организатор или модератор открывает очередь кнопкой «Ожидают входа» в шапке звонка. В очереди можно принять или отклонить заявку. Гость, которого впустили, переходит в звонок автоматически.

embedded call передаёт ответ HTTP 202 от `POST /v1/rooms/:roomId/join` в параметр `initialLobby` при вызове `mountWidget()`. Виджет следит за уже созданной заявкой, показывает таймер и обрабатывает отмену. После допуска виджет получает токен входа и запрашивает устройства.

### Палитра embedded call (используется в демо)

| Токен | Значение |
|---|---|
| background | `#05080f` |
| surface / elevated | `#0e1522` / `#121b2c` |
| primary/accent | `#8576ff` |
| onPrimary | `#ffffff` |
| text / muted | `#f4f7fb` / `#99aac0` |
| border | `#1e2a3f` |
| radius | 12–18px |
| font | Inter (headings −0.02em, weight 700–800) |
| brand | моноширинный uppercase, letter-spacing 0.12em |

## 5. Правила

- Скрывать контролы, но не ломать клавиатурные сокращения и API — доступность
  проверяется правами (`resolveAccess`), лейаут — только визуальный слой.
- `hiddenControls` не отключает функцию: mic/camera можно переключить API-методом
  или горячей клавишей; если нужно полностью выключить — используйте
  `features.*`/`accessPolicy`.
- После смены лейаута виджет перерисовывает контролы без перезагрузки; состояние
  звонка сохраняется.
- Для iframe-встраивания `chrome:'none'` + `island` дают «нативный» вид в UI
  компании; мини-окно (`minimized.mode:'bubble'`) — поверх страниц.

## 6. Ограничения

- Позиции задаются внутри виджета; глобальное «перетаскивание» острова
  пользователем (drag-and-drop) — roadmap.
- Свободное размещение произвольных кнопок (не из `controlIds`) — roadmap
  (кастомные действия через API).
- В режиме broadcast у зрителя набор контролов ограничен правами (см.
  `agil/core/docs/scaling.md` §6).
